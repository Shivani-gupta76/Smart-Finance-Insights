# 💰 Smart Finance Insights (FinSight)

A full-stack Personal Finance Management System built using **Flask**, **SQLAlchemy**, **HTML**, **CSS**, **JavaScript**, and **Chart.js**. The application helps users manage their income, expenses, budgets, and financial accounts while providing interactive dashboards and visual insights.

---

## 🚀 Features

### 🔐 User Authentication
- User Registration
- User Login
- Secure Logout
- Password Hashing

### 📊 Dashboard
- Financial Overview
- Total Income
- Total Expenses
- Current Balance
- Budget Summary
- Monthly Expense Trend
- Expense Breakdown (Pie Chart)
- Recent Transactions

### 💸 Expense Management
- Add Expense
- Edit Expense
- Delete Expense
- View All Expenses
- Link Expenses to Accounts

### 💵 Income Management
- Add Income
- Edit Income
- Delete Income
- View Income History

### 🏦 Account Management
- Create Accounts
- Edit Accounts
- Delete Accounts
- Automatic Balance Updates

### 🎯 Budget Management
- Create Budget
- Track Budget Usage
- Remaining Budget Calculation

### 👤 User Profile
- View Profile Information
- Update Profile Details

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/Shivani-gupta76/Smart-Finance-Insights.git
```

Move into the project folder

```bash
cd Smart-Finance-Insights
```

Create a virtual environment

```bash
python -m venv .venv
```

Activate the virtual environment

Windows

```bash
.venv\Scripts\activate
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
